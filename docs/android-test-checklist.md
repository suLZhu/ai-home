# Android 真机验收清单（4.8）

> 4.8 默认是**本地模式**：装好 APK 直接可用，不需要先起服务器。只有要云同步 / 多设备时才需要填服务器地址（设置 → 关于栖间 → 云同步服务器 / 调试）。
> 记录格式：日期 / 机型 / Android 版本 / 结果（通过 / 问题描述）。

## A. 安装与启动
1. **安装启动**：装 Debug APK，首次启动进首页；无闪退、无白屏。
2. **版本号**：设置 → 关于栖间 显示 `v4.8`。

## B. 本地数据
3. **本地保存**：聊天几条消息后杀进程重开，消息还在。
4. **备份**：设置 → 数据 → 备份与恢复，点「整体数据 → 备份」，文件出现在「下载/栖间/」。
5. **恢复**：清掉一条记忆后点「记忆 → 恢复」，内容回来。

## C. 聊天
6. **收发消息**：文字消息流式输出正常。
7. **图片**：相册选图 → 发送 → 消息里显示图片 → 点开放大 → 返回键关闭。
8. **重启后图片仍在**：杀进程重开，历史图片还能显示。
9. **长按菜单**：复制 / 编辑 / 重发 / 删除可用。
10. **气泡样式**：设置 → 主题 → 气泡，切换后聊天里样式跟着变。

## D. 供应商与模型
11. **添加供应商**：设置 → 供应商 → ＋添加，填名称 / Key / 地址，保存后列表显示 `1 Key · 0 模型`。
12. **启用与隐藏**：详情页「隐藏 / 启用」在同一行，两个开关都生效；隐藏的供应商只出现在列表「隐藏」筛选里。
13. **多 Key**：打开多 Key 模式，Key 列表和添加表单内联在下方，不跳页。
14. **模型页**：点卡片进「编辑模型」；长按卡片进入多选（出现 全选 / 测试 / 删除 / 退出）。
15. **模型测试**：选中模型点「测试」，弹出小卡片，文本 / 图片 / 工具三项各自 ✓ / ✗；没配 Key 时显示「缺少 API Key」。

## E. 记忆
16. **手动新增**：记忆面板 → 手动新增记忆，保存后列表出现该条（已生效）。
17. **自动整理**：攒够阈值后打开记忆面板会自动整理一次，「上次整理」显示新增条数；整理后待整理量归零。
18. **AI 整理**：记忆治理 → AI 整理，提示「看了 N 条，合并/改写后新增 X 条，归档 Y 条」。
19. **记忆模型**：面板顶部可选择「整理模型 / 向量模型」，保存后重开仍在。

## F. 外观
20. **美化包**：设置 → 主题 → 美化包，导入 json/zip 后点一下应用；首页、设置、侧边栏背景一起变。
21. **平铺**：应用美化包后，设置列表 / 首页卡片没有白色卡片底，只剩细线分隔。
22. **图标**：设置列表图标是线性 SVG（不是 ✎ ▱ 这类符号）。

## G. 移动端交互
23. **返回键层级**：图片灯箱 → 搜索 → 多选 → 面板逐层关闭；聊天 → 房间 → 首页。
24. **软键盘**：点输入框键盘弹出后输入框可见；收起后布局恢复。
25. **安全区**：刘海屏 / 挖孔屏顶部内容不被遮挡；底部手势条不压住输入框。

## H. 提醒（可选）
26. **到点提醒**：设一个 1 分钟后的提醒，锁屏等它响；点通知进聊天。
27. **重启恢复**：重启手机后，未触发的提醒仍在。

## 附加观察（不阻塞验收）
- 长聊天滚动顺滑，无可见系统滚动条。
- 会话内搜索可定位消息。
- 图片长按是否弹出 WebView 原生菜单（如影响体验再最小修复）。
