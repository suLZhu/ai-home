# Android 真机手动验收清单（15 项）

> **前置（电脑端一条命令 + 手机端一次设置）**：
> 1. 电脑运行 `npm start`：脚本自动备好登录密码与跨域配置、把服务绑到局域网，
>    并打印出手机要用的 **API 地址**（`http://<局域网IP>:4180`）和 **登录密码**。
> 2. 手机与电脑连同一 Wi-Fi，安装 Debug APK（支持明文 HTTP）。
> 3. 手机端一次性设置：设置 → 开发者 → API 服务器地址 = 打印的地址 → 输入打印的密码登录（7 天免登）。
> 4. 跨源凭证走 token（Bearer / `?token=`），不再依赖跨源 Cookie，无需 HTTPS 反向代理。
>    Release 版若对外发布仍应使用 HTTPS 地址。

## A. 安装与启动
1. **安装启动**：安装 Debug APK，首次启动出现奶灰+浅紫启动图，随后进入登录页；无闪退、无白屏。
2. **图标观感**：桌面图标为奶灰底浅紫小房子（占位图，正式图标后续由 顾惟/晏未晞 提供）。

## B. 登录与会话
3. **登录保持**：输入密码登录成功；杀掉 App 再打开，仍是已登录状态（登录 token 持久化在本地，7 天内免登）。
4. **会话过期**：服务器重启后打开 App，应提示重新登录，而不是静默失败。
5. **离线云恢复**：断网打开 App，走 Phase 8 的本地数据保护路径，不因拉不到云端而清空本地。

## C. 聊天与附件（重点回归）
6. **收发消息**：正常发送/接收文本，流式输出正常。
7. **相册选图→上传→发送→显示**：从相册选图，缩略图正常，发送后消息里显示图片。
8. **图片预览**：点击图片放大（灯泡图）正常，返回键关闭灯泡图。
9. **App 重启后图片仍在**：重启后历史图片能从服务器取回显示（`assetId + /api/attachments/<id>`，非 `blob:`）。
10. **删除附件引用检查**：删除含图消息后，服务器端附件引用计数正确（不误删仍被引用的图）。

## D. 移动端交互
11. **返回键层级**：灯泡图→搜索→多选→表情/更多面板，逐层关闭；全部关闭后聊天页→房间；房间页按返回退出 App。
12. **软键盘**：点输入框，键盘弹出后输入框仍可见；收起键盘后布局恢复，无错位。
13. **安全区**：刘海/挖孔屏顶部内容不被遮挡；底部手势条不压住发送按钮。

## E. 开发者与诊断
14. **API 地址覆盖**：设置→开发者→改 API 服务器地址并保存，后续请求发往新地址；恢复默认后回到同源。
15. **请求诊断可用**：发送一条消息后，开发者→模型请求诊断能看到本次请求快照（脱敏正常、无凭证）。

## 附加观察项（不阻塞验收）
- 长聊天滚动顺滑，无可见系统滚动条。
- 会话内搜索可定位消息。
- 长按消息菜单可用（注意与系统文本选择的冲突是否可接受）。
- 图片长按是否弹出 WebView 原生菜单（如影响体验再最小修复）。
