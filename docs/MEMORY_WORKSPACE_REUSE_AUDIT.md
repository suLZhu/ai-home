# 记忆、世界书、工作区复用核对（2026-11-19）

## 本轮结论

已核对正式版主分支 `src/App.tsx`、`src/MemoryPanel.tsx`、`src/WorldbookEditor.tsx` 与 `src/WorkspaceSettings.tsx`。这些是真实存在的功能组件，不能把原型占位页当作功能已完成。

## 接入原则

1. 固定新版主页、聊天、设置和房间的一级布局；从二级入口调用已有组件，不复制、重写原功能代码。
2. **世界书**：重用 `WorldbookEditor`，其 `entries/onChange/personLabel` 必须接入当前应用唯一的 `worldEntries/setWorldEntries` 状态。个人世界书编辑保持原版的绑定角色过滤与合并逻辑，避免误删其他助手条目。
3. **记忆**：`MemoryPanel` 不只是展示卡片，还依赖 `person`、`personMessages`、`modelOptions`、会话跳转回调以及整理/精简记忆的执行函数。不能简单在原型中传入假消息或一个空函数，否则看起来可用、实际上不能查询和整理。
4. **助手资料**：沿用正式版 `AssistantProfile` / `ToolPanel` 对应的数据与动作，不在原型重新实现。
5. **工作区**：保留 `WorkspaceSettings` 和已有本机文件功能；之后在后台扩展助手可调用的诊断工具，技术操作默认不打扰用户。自动修复需要权限与审计。
6. **中文界面**：页面导航、表单说明、状态、错误全部简体中文；模型 ID、网址、协议标识等技术字段保持原样。

## 代码依赖核查

- `src/App.tsx` 第 2625 行附近：按当前助手过滤并合并世界书绑定，不能用简单覆盖数组替代。
- `src/App.tsx` 第 2629 行附近：打开记忆面板，注入聊天记录、模型候选和整理回调。
- `src/App.tsx` 第 3804 行附近：现有设置页面按助手打开记忆。
- `src/App.tsx` 第 4845 行附近：资源库已有世界书编辑器入口。
- `src/WorkspaceSettings.tsx`：已有工作区配置组件，可复用。

## 本轮未做

未把上述组件直接挂进纯演示版 `LayoutPrototype`，因为该原型没有与正式版共享的真实聊天、世界书和记忆状态。后续需要先统一应用状态/路由，再挂现有组件；不可创建第二套独立数据导致用户修改不生效。此文档仅记录代码审查结论。
