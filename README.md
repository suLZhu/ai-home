# 私人 AI 前端 · 空房子原型

独立于 Kelivo 的 React + TypeScript + Vite 原型。

## 当前实现
- 书页风格的首页和房间目录
- 晏未晞、言朔各自的房间与临时本地消息
- 各自工作区入口（人物提示词、世界书、长期记忆、定时任务、MCP、模型设置）
- 公共客厅占位

**尚未实现**：AI 接口、消息持久化、Serein、PocketBase、MCP、定时任务执行和群聊。

## 本地运行
```bash
npm install
npm run dev
npm run build
```

不修改 Kelivo，不占用现有 PocketBase 服务。
